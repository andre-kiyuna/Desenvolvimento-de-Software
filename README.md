# ☕ Desenvolvimento de Software

Repositório com exercícios e atividades práticas da disciplina de **Desenvolvimento de Software** do curso de Engenharia de Software — Universidade Positivo.

## 📚 Sobre

Repositório em uso ativo (semestre atual). Os exercícios abordam conceitos fundamentais de Programação Orientada a Objetos em Java, incluindo classes, herança, polimorfismo, interfaces e classes abstratas.
